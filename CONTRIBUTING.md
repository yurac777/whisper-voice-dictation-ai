# 🤝 Contributing to Whisper Voice Dictation AI

Thank you for considering contributing to **Whisper Voice Dictation AI**! We welcome bug reports, feature requests, pull requests, and documentation improvements.

---

## 🛠️ Local Development Setup

1. **Fork and Clone the Repository:**
   ```bash
   git clone https://github.com/yurac777/whisper-voice-dictation-ai.git
   cd whisper-voice-dictation-ai
   ```

2. **Set Up a Virtual Environment:**
   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   ```

3. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

4. **Run the Application:**
   ```bash
   pythonw main.py
   ```

5. **Test Building the Executable:**
   ```bash
   build_exe.bat
   ```

---

## 📥 Pull Request Guidelines

- Ensure your code follows PEP8 standards.
- Test keyboard hotkeys and sounddevice recording on Windows 11.
- Open a GitHub issue to discuss major feature changes before creating a pull request.
