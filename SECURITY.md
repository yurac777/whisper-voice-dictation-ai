# 🔒 Security & Privacy Policy

## 🛡️ Offline & Privacy Guarantees

**Whisper Voice Dictation AI** is designed with privacy as its primary principle:

- 100% Offline Processing: All speech recognition is performed locally on your computer using INT8-quantized OpenAI Whisper models.
- Zero Cloud Telemetry: No audio data, transcriptions, or personal metrics are ever transmitted over the network.
- Portable File Logging: Logs are saved exclusively in `app.log` in the local application folder.

---

## 🐛 Reporting Vulnerabilities

If you discover a security issue or vulnerability, please report it by opening a private GitHub Issue or reaching out directly to the maintainer.
