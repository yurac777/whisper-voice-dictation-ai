# 🎙️ Whisper Voice Dictation AI (AMD Ryzen AI 9 Optimized)

Высокоскоростное приложение для ИИ-диктовки и распознавания речи на русском языке.

## 🚀 Особенности:
- **Управление по клику колесика мыши:** Нажмите колесико в любом месте Windows, надиктуйте текст и нажмите колесико еще раз.
- **Прямая вставка в окно:** Распознанный текст автоматически вставляется в активную строку ввода (Telegram, Word, браузер и т.д.).
- **Отмена клавишей ESC:** Нажмите `ESC` или кнопку `❌ Отмена` для моментального сброса записи.
- **Буфер истории:** Нажмите `📋 История` для доступа к списку ранее надиктованных фраз.
- **Ускорение на AMD Ryzen AI 9:** Обработка за 0.2 - 0.4 секунды на 20 потоках CPU с INT8 квантованием.

## 🛠️ Запуск:
Запустите `run.bat` или кликните ярлык на Рабочем столе.
